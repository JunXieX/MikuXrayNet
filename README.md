# MikuXrayNet

MikuMC 服务器自研的 **反矿透 + 带宽优化** 插件（Paper 26.2 / Java 25 / 兼容 Folia）。

目标是在**功能完备度**与**性能、带宽占用**两个维度都做到尽可能好：能异步的一律异步、能少发一个字节就少发一个字节。

---

## 功能总览

### 一、反矿透（AntiXray）

| 能力 | 说明 |
| --- | --- |
| 掩埋判定 | **6 个正交邻面全部被遮挡**的方块才伪装——也就是真正被埋住、透视客户端会透过墙看到的那些；暴露在空气/洞穴里的方块保持原样 |
| 邻区块贴边快照 | 抓取 4 个邻区块贴边的 1 格厚平面参与判定，**消除区块边界那一圈永不伪装的泄漏**；邻块缺失时的策略可配（默认宁可多伪装） |
| 伪装方块 | 按权重随机选取；支持同层统一（layer 模式）；被伪装 section 内的方块实体同步剔除 |
| 邻近显形 | 玩家靠近曾被伪装的坐标时主动发回真实方块状态；服务端自身下发该坐标变更时同步注销记录，避免陈旧数据 |
| 权限直通 | 持有 `mikuxraynet.bypass` 的玩家完全不被伪装 |

### 二、带宽优化（Bandwidth）

| 能力 | 说明 |
| --- | --- |
| 零位移包取消 | 位移与旋转增量**全为 0** 的实体移动/旋转包直接不发送 |
| 方块变更合并 | 「曼哈顿距离 2 邻域」内的多条变更合并成**一条** `MULTI_BLOCK_CHANGE` 再下发（合并包带首包回读自检，未通过则原包照常放行） |
| 调色板压缩重排 | 按出现频次把高频方块排到低 id，改善网络层压缩率；只作用于被改写的 section，语义与字节往返一致性均有单测保证 |
| 实体剔除 | 异步体素射线判定遮挡，隐藏看不见的实体；带强制可见距离兜底 |
| AFK 降级 | 按方块坐标变化判定活动，AFK 玩家按距离丢弃低价值包（世界粒子、方块破坏动画） |
| 高延迟降视距 | ping 超阈值且持续一段时间的玩家自动降低视距，恢复后还原 |

## 技术架构

- **封包通道：ProtocolLib 真异步扣包**。它是唯一拦截通道；重活全部在自有线程池完成，Netty 线程不做任何计算，只登记任务后立即让出。
- **区块编解码：自研纯字节 codec**。只重编码**真正被改动**的 section，未改动的 section 原字节搬运；全实心 section 直接跳过判定。
- **方块状态映射：PacketEvents 仅启动期使用**。启动时构建状态位图（空气/流体/遮挡/权重表），此后热路径**零 PacketEvents 引用**。
- **内存纪律**：缓存键只含世界名与坐标等基本类型，**绝不持有 `World` / `Chunk` / `Player` / 封包对象**；世界卸载即整体失效。这是相对参考实现（其卸载世界会泄漏内存）刻意做的强化。
- **全程 fail-open**：超时、队列满、任何异常都放行原包，绝不卡住玩家；延迟放行的包保证恰好放行一次。
- **不使用 NMS**，因此对服务端版本升级稳定，且天然兼容 Folia（世界访问一律走区域调度器）。

## 配置

首次启动自动生成两份**独立**配置文件，互不混杂，且**全部带中文注释**：

- `antixray.yml` —— 反矿透：世界与高度范围、伪装权重表、邻近显形、邻区块策略、缓存、线程与超时
- `bandwidth.yml` —— 带宽优化：零位移取消、变更合并窗口、调色板重排、实体剔除、AFK、高延迟降视距、诊断

`/mikuxraynet reload` 可热重载；命令会明确告诉你哪些项即时生效、哪些需要重启。

---

## 命令与权限

| 命令 | 说明 |
| --- | --- |
| `/mikuxraynet status`（别名 `/mxnet`、`/mxr`） | 查看运行状态：依赖、改写缓存命中率、改写/显形/带宽各项统计、线程池水位 |
| `/mikuxraynet dump` | 导出完整诊断转储文件并在聊天栏回显路径 |
| `/mikuxraynet reload` | 热重载两份配置并重建周期任务 |

权限：`mikuxraynet.admin` / `status` / `dump` / `reload` / `bypass`
